# 从独立 Skill 快照迁移

旧公开版本的入口位于根目录 `design-forge/` 和 `dewu/`。当前版本使用完整基础组件和可选品牌包，通用入口位于 `skills/`，品牌源位于 `brand-packs/`，实际宿主加载构建后的独立部署。

1. 将用户自行修改的品牌规则、脚本和项目产物备份到仓库外。
2. 安装 Node.js 24+，在当前源码目录运行 `npm ci`。
3. 选择通用、得物或京东，构建到一个新的外部目录。
4. 将宿主旧 Skill 注册替换为新部署；不要同时注册两套入口。
5. 运行诊断，并用一个独立项目验证所需能力后再切换日常工作。

旧版品牌文件不是品牌 API v1 清单，需要按开发规范整理成外置私有包；不要直接覆盖新基础组件。原有产物与确认记录不自动导入为已验证项目。

本次更新保留公开仓 Git 历史。当前发行树移除了旧证据说明、内部路径和过程性示例，旧提交仍可能包含这些内容；这不是历史清理版本。
