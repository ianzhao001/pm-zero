# Evidence Grading Stage Application

本文件按需补充 `evidence-grading-protocol.md`，不重定义 A–E。

## Stage Application

- Idea/MRD：标注市场、用户需求、目标人群、问题严重度和商业机会论断。
- Interaction spec：标注由用户行为、环境、上游产物或场景假设驱动的交互与信息架构选择。
- Demo：实现细节无需标级；Demo 新增的用户行为、产品价值或数据论断仍须标级。
- PRD：标注用户价值、业务收益、数据指标、优先级与范围取舍依据。

## Source Annotation

- Source-backed：给出路径、URL、报告名、访谈引用或用户提供产物。
- Assumption-backed：写 `assumption - pending live validation`，并登记验证方式。
- Derived：点名推导所依据的 accepted artifact 或 decision record。
