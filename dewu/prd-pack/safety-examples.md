# Dewu PRD 安全示例

通用的业务安全 / 内容安全拆分规则见 `../../prd-forge/references/scope-boundary.md`。本文件只给 Dewu 语境下的领域示例。

## 业务安全示例

- 毒币发放、兑换、拍卖、排行榜奖励、活动开奖、优惠资格、账号设备限制。
- PRD 需写清 AC、异常路径、owner、对账或补偿口径。

## 内容安全示例

- 毒评、评论、图片、穿搭内容、举报、审核、社区互动风险。
- PRD 需写清审核状态、屏蔽/下架策略、申诉或运营处理路径。

## 不要混写

同一活动既有奖励又有评论时，奖励风控和评论审核拆成两条规则或两个子段。
