# Dewu 交互反馈模式

本文件只保留 Dewu 专属反馈。通用原稿保真、Type 1/Type 2、tap feedback、Sheet 高度、主辅 CTA、版本策略和 CSS/JS 陷阱已归入 `../../design-forge/references/interaction-feedback-patterns.md`。

## 0. 截图事实优先

- 上传的四张得物截图是设计语言事实证据；设计语言、视觉规范、页面结构样式与本地规则冲突时，以截图为准。
- 该优先级不覆盖仓库协议、发布边界、隐私边界、工具接口、测试运行方式或截图不能证明的业务事实。
- `dewu-interaction-design` 只能作为背景资料；不得覆盖截图中已经证明的 Tab 结构、字号、图标、Feed、颜色和角标规则。
- 截图只证明对应 surface：`得物` 推荐 Tab 的双列 Feed 不外推为 `购买`、`探索`、`我` 的页面结构。

## 1. Dewu DS 合规

- 手机屏幕内部默认浅色：页面 `var(--n-bg)`，卡片 `var(--n00)`。
- 主 CTA 使用 `var(--accent)`；红色只用于风险、热度、警告、折扣或破坏性动作。
- 主价格、资产、保证金、权益价值默认用 `var(--n140)` 或中性色，不用促销红抢主视觉。
- 不新增硬编码灰色和临时色值；灰阶从 N 色阶里选最近 token。
- 底部 Tab 默认使用 得物 / 购买 / 探索 / 我 四 Tab。
- 顶部社区 Tab 顺序固定为 推荐 / 极光街 / 运营活动 / 灵感 / 关注 / 穿搭；活动可替换第 3 个 Tab 的展示名，但不改变逻辑位置。
- Type 1 入口容器页才显示顶部社区 Tab 和底部 4 Tab；Type 2 Push 页只显示返回导航，不显示顶/底 Tab。
- 商品图、装备图或用户内容图应成为首屏视觉主角；不要用大面积抽象渐变、空白卡片或图标替代商品内容。
- 底部 Tab icon 在最终 HTML 中使用清晰 SVG stroke-only 或真实线框资产；不要用填充块、生成式复杂图标、纯文字、emoji、字母圆点、CSS 伪元素或模糊占位图。
- 底部 Tab active 使用 `--n140`，顶部社区 Tab active 才用 `--accent` 下划线表达当前频道。
- `得物` 推荐 Tab 的顶部 active 下划线使用 `--accent`，不得被旧本地规则改成 `--n140`。

## 2. Dewu 社区融合

- Dewu 社区语境下，活动或竞猜详情应融合讨论流、复盘、装备、商品或内容承接。
- 讨论 Tab 只显示评论；热门内容 Tab 才显示复盘、装备、商品、比率等内容。
- 评论和内容要有真实社区密度：不同立场、不同语气、点赞/回复信息，避免空洞占位。
- 若缺少讨论数据，构造具体、有立场、有参与数值/点赞的观点样例；观点可以有对抗性，但不做人身攻击。
- 活动页不能只像交易或运营落地页；至少给出一个社区承接入口，例如讨论、晒单、复盘、榜单、装备清单或热评。
- 热门内容卡需要明确内容类型：穿搭、装备、复盘、晒单、测评或话题，不把评论列表伪装成内容流。
- 推荐 Tab 顶部频道后直接进入双列 Feed，不增加截图中没有的品牌背书 chip row、热帖 chip row 或功能捷径行。
- 推荐 Feed 的点赞图标统一为右侧 thumbs-up 描边图标 + 数字，不混用 heart。
- 推荐 Feed 卡标题最多 2 行，作者和点赞 meta 单行收束，避免文本随机撑高。
- 推荐 Feed 卡不出现 `AUTH` / `NEW` 标签，除非用户提供新的截图或明确要求。

## 3. Dewu 业务态压缩

- 得物活动中的倒计时、资金流、仓位、奖励进度必须行内化或标签化，避免撑爆卡片。
- 详情页避免重复指标和重复倒计时；同类信息合并为一个状态表达。
- 涉及毒币、鉴定、开奖、兑换、排行榜奖励时，界面要给出状态、异常和承接入口。
- 倒计时遵循三档：天级弱提示、当天中提示、一小时内强提示；同一卡片只保留一个主倒计时。
- 鉴定中、鉴定失败、毒币不足、奖品已兑完、开奖延迟、榜单冻结、奖励待发放都需要明确下一步：查看规则、联系客服、补足权益、等待公示或返回活动。

## 4. Dewu 迭代边界

- 当用户要求“只改样式”时，不改底部 Tab、业务流程、奖励规则或社区信息架构。
- 当用户要求删除模块时，删除视觉模块、入口、路由、状态文案和 demo 跳转，不留下残余热点。
- 当用户要求同步上传版的好约束时，只吸收可迁移的布局、反馈、检测和边界方法；Dewu 私有 token、签名、tab、研究只留在本 pack。

## 5. Dewu 输出自检

1. 检查底部 Tab 文案顺序：得物 -> 购买 -> 探索 -> 我。
2. 检查顶部社区 Tab 文案顺序：推荐 -> 极光街 -> 运营活动/活动名 -> 灵感 -> 关注 -> 穿搭。
3. 检查 Type 2 页面没有 `.top-tabs` 或 `.tabbar`。
4. 检查社区 Feeds 是双列 `.feed-grid`，讨论/观点/排行使用单列 list class。
5. 搜索旧 token：`#FF2E4D`、`#FF4657`、`#D7D7DE`、`#5A5A66`、`#2B2F36`、`oklch(` 应为 0。
6. 搜索 `grid-template-columns: repeat(5`，确认未恢复五 Tab。
7. 检查 `.price` / `.main-price` 没有使用红色促销语义。
8. 检查输出原型含 `@ianzhao` 签名。
9. 搜索 `先鉴别后发货`、`今日热帖`、`穿搭灵感`、`AUTH`、`NEW`，确认没有把截图外幻想写进推荐 Feed。
10. 检查 `.like svg path` 在同屏一致，且为 thumbs-up 描边样式。
