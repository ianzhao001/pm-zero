# PRD 图文格式约束

## 来源与用途

本文档吸收自 magi-product `lead-pm-prompt.md` 的图文格式约束,用于约束 PRD 与方案文档的**表达形态**（文字/表格/Mermaid 三态与禁 ASCII 框图）；docx 排版细则（标题/表格/图片/超链接）唯一正文是 `format_spec.md`,两者不重叠。

## 允许的三种表达

1. **文字**:用于解释背景、目标、规则、边界和决策理由。
2. **表格**:用于列元素清单、字段清单、验收标准、优先级、状态机。
3. **Mermaid**:用于表达流程、状态转换、依赖关系、泳道协作。

## 严禁 ASCII 框图

不得使用以下形态表达架构或界面:

```text
┌──────┐
│ 按钮 │
└──┬───┘
   ▼
```

原因:

- 不利于复制、维护和 diff。
- 多端字体渲染不稳定。
- 复杂后容易被误读为真实 UI。

## 严禁用文字画 UI

- ❌ 反例:`[头像] [昵称] [关注按钮]`。
- ✅ 正例:用表格列出界面元素,或用 Mermaid 表达流程,真实 UI 交给交互稿 / Demo。

## 纯中文表达原则

- 默认使用中文描述产品语义、交互逻辑、验收标准。
- 行业专有名词可保留英文,例如 API / ID / PDF / URL。
- 若英文术语有稳定中文表达,优先中文。

## 中英术语映射

| 英文术语 | 中文表达 | 说明 |
|---|---|---|
| Toast | 轻提示 | 短时反馈,不阻断操作 |
| Modal | 弹窗 | 阻断式浮层 |
| Skeleton | 骨架屏 | 内容加载前的占位状态 |
| Empty State | 空态 | 无数据或无结果状态 |
| Loading | 加载中 | 请求或计算未完成状态 |
| Disabled | 置灰/不可用 | 不满足操作条件 |
| Tooltip | 悬浮提示 | 辅助解释信息 |
| Tab | 标签页 | 同层级内容切换入口 |
